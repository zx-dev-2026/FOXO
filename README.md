# FOXO

FOXO 是一款本地 AI 模型路由网关与桌面交互客户端，旨在把多个渠道的模型资源集中到一个入口，方便用户查看、测速、选择并进行对话。

> 项目介绍提及：内置 7 组、60+ 个模型资源。可用模型、渠道和功能可能随版本及上游服务变化，请以软件内实际展示为准。

## 功能概览

- **集中管理模型**：在模型页面查看可用资源并测试响应速度。
- **多渠道接入**：按软件提供的流程验证或登录，获取相应渠道的模型资源。
- **灵活选模**：在统一的选模页面选择单个模型、多个模型或整组模型。
- **本地网关与路由**：通过统一入口管理模型调用，并按软件中的配置进行路由与分发。
- **桌面交互**：在客户端或桌宠模式中与模型对话，可将桌宠常驻桌面。

## 快速开始

1. 下载并启动 FOXO。
2. 打开模型页面，查看可用模型及其响应状态；需要时运行测速。
3. 如需添加其他渠道的资源，按软件中的提示完成验证或登录。
4. 在选模页面选择要使用的模型或模型组。
5. 在客户端或桌宠中发起对话，并按需调整路由配置。

软件界面和渠道流程可能随版本变化；如果遇到与上述步骤不一致的情况，请以当前版本中的提示为准。

## 常见问题

### 模型不可用或测速失败怎么办？

先检查网络连接、所选渠道的登录或验证状态，以及模型在软件内是否仍然可用。不同渠道的服务状态和限制可能不同；稍后重试或切换模型，并查看软件给出的错误提示。

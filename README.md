# FOXO

FOXO 是一款本地化的 AI 模型路由网关与桌面交互客户端，可聚合多家服务商及渠道中的模型资源，并通过统一入口进行配置、测速、选择和调用。

## 项目简介

FOXO 面向希望在本地集中管理多个 AI 模型的用户，提供模型统一调度、渠道资源同步与桌面对话等能力。安装后即可使用软件内置的模型资源，也可以按需接入其他渠道。

## 核心功能

### 模型网关与调度

- 内置 7 组、60+ 个模型资源。
- 在模型页面查看可用模型并进行响应速度测试。
- 按用户配置进行网关路由与分发。
- 在统一的选模页面中选择单个、多个或整组模型。

### 多渠道模型接入

- 支持通过密钥验证获取额外免费模型资源。
- 支持通过服务商登录获取对应的模型资源。
- 来自不同渠道的模型与服务商资源可在选模页面统一展示和管理。

### 桌面交互与对话

- 支持在桌宠模式下或客户端界面中与 AI 模型进行实时对话。
- 支持将虚拟桌宠常驻桌面，提供便捷的交互入口。

## 使用说明

1. 安装并启动 FOXO。
2. 在模型页面查看内置资源及其响应状态。
3. 如需更多模型，在白嫖或服务商页面完成相应验证。
4. 在选模页面选择需要使用的模型。
5. 通过桌面客户端或桌宠模块发起对话。

# FOXO
一个聚合了几家提供商的本地路由器。

## 软件概述
FOXO 是一款本地化部署的 AI 模型网关与交互客户端。其核心机制在于通过本地路由，聚合多个不同服务商与渠道的 AI 模型资源，并提供统一的调度与调用接口。同时，软件内置了桌面交互模块，扩展了 AI 的使用场景。

## 核心功能模块

### 1. 网关与模型调度
- **内置资源**：软件原生内置 7 组共 60+ 个模型，安装后可直接调用。
- **测速机制**：在“模型页面”提供测速功能，用于实时检测各模型的响应状态。
- **网关分发逻辑**：网关接口严格按照用户的配置进行路由。所有可用模型会统一汇总至“选模型页面”，用户可在此自由选择单组、多组或单个模型进行组合搭配。网关仅调用被选中的模型，未选中的模型不会触发调用。

### 2. 多源模型获取
- **白嫖页面**：提供密钥验证机制，用户可通过输入对应密钥获取额外的免费模型。
- **服务商页面**：提供手机号登录机制，用户登录后可获取对应的白名单模型。
- 以上所有渠道获取的模型及服务商资源，均会实时同步并统一展示在“选模型页面”中。

### 3. 桌面交互与 AI 对话
- **桌宠模块**：软件后续版本追加的交互功能。支持在软件内部开启虚拟桌宠，常驻桌面。
- **实时对话**：支持在桌宠形态或客户端界面进行实时的 AI 对话交互。
